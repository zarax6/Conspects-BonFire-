#### Классификация погрешностей

1. Раздел вычислительной математики в котором вычисляются способы математических задач, которое либо не имеет решения, либо оно слишком сложное
2. Итерационность - это подход, при котором сложная задача решается не сразу, а через серию последовательных шагов (итераций)
3. Приближенность - представляем число в приближенном виде

Приближенное число - это число, несильно отличающееся от исходного и заменяющее его в выражение

Погрешностью приближения - разница между точным и приближенным значением, и она может принимать как положительные или отрицательные значение.

x - точное число
x* - приближенное
x* ≈ x
3,14 ≈ П

#### Источники погрешностей
1. Математическая модель - идеализированное представление сущности, которая выделяет основные черты и отбрасывает второстепенные.

2. Погрешность исходных данных - составляющая погрешности обусловленная неточностью данных в ходящих в условии задачи. Совокупность погрешности математической модели и погрешности исходных данных образуют неустранимую погрешность.

3. Погрешность метода - составляющая погрешности, обусловленная заменой исходной математической задачи другой задачи, которая точно решается точно решается данным математическим методом. Обусловленные соответствия несоответствующей математической модели реальной сущности.

4. Вычислительная погрешность - составляющая погрешности, обусловленная необходимостью выполнять арифметические операции над числами, усеченные до количества разрядов зависящего от применяемой вычислительной техники.

Полная погрешность △(Полная) = △(неустранимая) + △(метода) + △(Вычислительной)
△ - погрешность

#### Классификация погрешностей
Абсолютная и относительная погрешность

Абсолютной погрешностью приближенного значения - называют величину △. про которую известно что |x = x*| ≤ △, где:
△ - Абсолютная погрешность
x - точное значение
x* - приближенное значение

Относительная погрешность - это когда выполняется следующее неравенство:

|x - x*| ≤ △(Предела)

x* - △(Предел) ≤ x ≤ x* + △(Предел)

x = x* ± Δ(Предел) 

Относительной погрешностью приближенного значения называют величину δ, про которую известно:
δ= Δ / x, где 
x ≠ 0
δ * 100%

Если пользуемся приближенным значением то,

δ = Δ / |x*|

Предельная относительная погрешность:

δ(Предельная) = Δ(Предельная)/|x*|

Δ = δ * |x|

Решение задания № 6 по шагам:

**Дано:**

* $a = 6,0 \pm 0,2$ (где $a^* = 6,0$, $\Delta a = 0,2$)


* $b = 4,0 \pm 0,1$ (где $b^* = 4,0$, $\Delta b = 0,1$)



---

### 1. Нахождение суммы $a + b$

* **Приближенное значение суммы:**

$$(a + b)^* = a^* + b^* = 6,0 + 4,0 = 10,0$$


* **Абсолютная погрешность суммы ($\Delta$):**
При сложении абсолютные погрешности складываются.

$$\Delta(a + b) = \Delta a + \Delta b = 0,2 + 0,1 = 0,3$$


* **Относительная погрешность суммы ($\delta$):**

$$\delta(a + b) = \frac{\Delta(a + b)}{(a + b)^*} = \frac{0,3}{10,0} = 0,03 \quad (3\%)$$



**Результат суммы:**

* $a + b = 10,0 \pm 0,3$

* $\Delta(a + b) = 0,3$

* $\delta(a + b) = 0,03$ ($3\%$)



---

### 2. Нахождение разности $a - b$

* **Приближенное значение разности:**

$$(a - b)^* = a^* - b^* = 6,0 - 4,0 = 2,0$$


* **Абсолютная погрешность разности ($\Delta$):**
При вычитании абсолютные погрешности также складываются.

$$\Delta(a - b) = \Delta a + \Delta b = 0,2 + 0,1 = 0,3$$


* **Относительная погрешность разности ($\delta$):**

$$\delta(a - b) = \frac{\Delta(a - b)}{(a - b)^*} = \frac{0,3}{2,0} = 0,15 \quad (15\%)$$



**Результат разности:**

* $a - b = 2,0 \pm 0,3$

* $\Delta(a - b) = 0,3$

* $\delta(a - b) = 0,15$ ($15\%$)



---

### 3. Сравнение результатов $\delta$ и вывод

* **Сравнение:**

$$\delta(a - b) = 15\% > \delta(a + b) = 3\%$$



Относительная погрешность разности существенно больше относительной погрешности суммы (в 5 раз).


* **Вывод:**
При одинаковой абсолютной погрешности ($\Delta = 0,3$) относительная погрешность вычитания резко возрастает. Это происходит потому, что при вычитании близких по значению величин знаменатель дроби $(a - b)^*$ уменьшается, из-за чего отношение абсолютной погрешности к самому числу значительно увеличивается. По этой причине операция вычитания приводит к сильной потере точности измерения/вычисления.
