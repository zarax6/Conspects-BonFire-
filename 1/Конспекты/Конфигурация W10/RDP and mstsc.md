## Что такое RDP?

RDP (Remote Desktop Protocol) — проприетарный протокол прикладного уровня, разработанный Microsoft, предназначенный для удаленного управления операционной системой (обычно Windows) с графическим интерфейсом.

- Порт по умолчанию: `3389` (TCP и UDP для оптимизации передачи графики).
- Архитектура: Клиент-серверная. На удаленном ПК должен быть включен RDP-сервер (доступен в редакциях Windows Pro, Enterprise, Server), а на подключающемся устройстве — RDP-клиент.
- Особенности: Передает не видеопоток, а графические команды отрисовки интерфейса (что экономит трафик).
	- Поддерживает проброс буфера обмена, локальных дисков, принтеров и аудио.
	- Шифрует трафик по умолчанию используя: TLS/NLA.

## mstsc

 mstsc.exe (Microsoft Terminal Services Client) — встроенный в Windows графический клиент для подключения по RDP.

### Запуск 
Чтобы запустить надо сделать: 
1. Надо показать свой IP для подключения к нему:
	1. Win + R
	2. cmd
	3. ipconfig
2. Дальше нам надо опять открыть Win + R и ввести туда уже mstsc соответственно
3. Вводим айпи с портом и мы подключены (IP:port)
