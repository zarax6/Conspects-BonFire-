## Что такое протокол RFB?

RFB (Remote Framebuffer) — простой открытый протокол прикладного уровня для удаленного доступа к графическому интерфейсу компьютера (GUI). Он лежит в основе технологии VNC (Virtual Network Computing).

- Порт по умолчанию: `5900` (для первой сессии / экрана `:0`). Каждый следующий экран использует порт `5901`, `5902` и т.д.

- Архитектура: Клиент-серверная. На управляемом ПК работает _RFB-сервер_, на управляющем — RFB-клиент (вьювер/viewer).

- Главный принцип работы: Протокол работает на уровне «пикселей». Сервер отправляет клиенту не команды отрисовки (как в RDP), а измененные участки кадра (фреймбуфера) в виде растровых изображений (картинок).

### Отличия от RDP:

- RDP: Привязан к Windows (на Linux требует сложных настроек xrdp), создает новую независимую сессию пользователя, передает инструкции отрисовки интерфейса (более экономичен к трафику).

- RFB (VNC): Кроссплатформенный (Windows, Linux, macOS). Он «зеркалит» физический экран — удаленный пользователь видит ровно то же самое, что и человек, сидящий перед монитором компьютера.

## Подключение через TightVNC

TightVNC — это популярная бесплатная программа с открытым исходным кодом, использующая протокол RFB. Она состоит из двух компонентов: TightVNC Server (для приема подключений) и TightVNC Viewer (утилита для самого подключения).

Для оптимизации трафика TightVNC использует алгоритм «Tight» — продвинутое сжатие (комбинация JPEG и zlib).

**Шаг 1**: Подготовка на стороне сервера (на удаленном ПК)

1. На удаленном компьютере должен быть запущен TightVNC Server.
2. В настройках сервера обязательно задаются два пароля:
- Primary password (Password): Для полного управления (мышь, клавиатура).
- View-only password: Только для просмотра экрана (без возможности управлять).

**Шаг 2**: Базовое подключение через Viewer
1. Запусти утилиту TightVNC Viewer на своем компьютере.

2. В поле Remote Host введи IP-адрес или имя удаленного ПК.
- Пример: `192.168.1.100`
- Если сервер запущен на нестандартном порту или это дополнительный экран, порт указывается через двоеточие или двойное двоеточие: `192.168.1.100::5901` или `192.168.1.100:1` (где `1` — номер экрана).
1. Нажми кнопку Connect.
2. Введи пароль, установленный на сервере.
