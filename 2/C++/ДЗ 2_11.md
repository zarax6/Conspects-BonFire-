
### Блок схемы

Обозначает пошаговые действия кода.

Ромб - Условие
Паралеллограм- Вход выход
Квадрат - Этап процесса
Овал - начало конец

### Типы данных

int - целое (-2 млрд до 2 млрд)
float, double - с плавающей запятой
bool - да нет
string - строка
### Условие

выражение в конце которого выдается положительный или отрицательный

#### Неполная конструкция ветвления

if без else

#### else if

Конструкция иначе если, выполняется если первый или предыдущий if не выполнен/не правильный, а условий несколько

#### Логич операторы

И/ИЛИ/НЕ 

И выводит ИСТИНА если оба выражения верны

ИЛИ выводит ИСТИНА если одно из двух верно

НЕ Инверсивное дейтвие делает

### Цикл

Повторяет действие до определенного значения

#### Пред пост условия

Предусловие - проверяет условие перед выполнением цикла 1 раз
Постусловие - проверяет условия после выполнения цикла 1 раз

#### While, do while, for

while - Предусловный цикл
do while - Постусловный цикл
for - цикл перебора по условию, смешанный

### Массив

упорядоченная структура данных, которая хранит фиксированное количество элементов одного типа под общим именем.

#### Ввод-вывод

для ввода нужен цикл for который проверяет до какого индекса нам надо заполнять

для вывода нужно указать индекс(ы) того что мы выводим

Замена - Присваивание нового значения элементу по его индексу

### Двумерный массив

То же самое что и одномерный, только для вывода ввода надо надо указывать индекс не только строки, но и столбца

Для ввода цикл for с ввоом строки столбца

Для вывода ввести строку столбец

### Размер массива

Надо использовать команду size
