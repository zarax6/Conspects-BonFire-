### Управление просмотром документов

Просматривать документ можно в разных режимах через вкладку **Вид**. Там можно выбрать режим разметки страницы, режим веб-страницы, а также включить или выключить боковую панель. Масштаб документа тоже настраивается во вкладке **Вид** — можно приблизить или отдалить страницу для удобной работы.

### Просмотр и перемещение внутри документа

Перемещаться по документу можно с помощью мыши, колёсика или полосы прокрутки справа. Также можно использовать горячие клавиши: **Ctrl+Home** — в начало документа, **Ctrl+End** — в конец документа, **Page Up** и **Page Down** — на страницу вверх или вниз. Ещё можно перемещаться по словам через **Ctrl+стрелочки**.

### Переход по закладке

Закладку можно поставить через вкладку **Вставка** — там есть кнопка **Закладка**. После создания закладки можно быстро перейти к ней через меню **Вставка → Закладка** или через навигатор, открываемый по клавише **F5**. В навигаторе отображаются все закладки документа, и по нажатию на нужную происходит переход.

### Использование гиперссылок

Гиперссылку можно вставить через вкладку **Вставка** — кнопка **Гиперссылка**. В открывшемся окне можно указать адрес сайта, файл на компьютере или место внутри документа. Также можно вставить ссылку на почту или на другую закладку. Готовую гиперссылку можно редактировать или удалять через контекстное меню по нажатию ПКМ.

## Практическая 6

### Оформление документа

Оформление документа делается через настройку шрифтов, абзацев, полей и разметки страницы. Шрифты и абзацы настраиваются во вкладке **Главное**, а разметка страницы — во вкладке **Разметка**. Также можно применять готовые стили через боковую панель стилей, открываемую по **F11**.

### Создание титульного листа

Титульный лист создаётся на первой странице документа. Для этого нужно вставить разрыв страницы после титульного листа, чтобы основной текст начинался со второй страницы. На титульном листе обычно размещают название работы, автора, учебное заведение и год. Выравнивание текста на титульном листе чаще всего делается по центру. Разрыв страницы вставляется через вкладку **Вставка → Разрыв страницы**.

### Создание списка литературы

Список литературы оформляется в конце документа. Для него можно использовать нумерованный список через вкладку **Главное**. Каждый источник оформляется по правилам: автор, название, издательство, год издания. Также можно вставлять гиперссылки на электронные источники через вкладку **Вставка → Гиперссылка**.

## Практическая 7

### Страницы и разделы документа

Документ можно разбивать на разделы через вкладку **Вставка → Разрыв раздела**. Разделы позволяют менять разметку страницы, колонтитулы и нумерацию для разных частей документа отдельно. Это удобно, когда титульный лист должен быть без номера, а основной текст — с нумерацией.

### Разбивка документа на страницы

Разбить документ на страницы можно через вкладку **Вставка → Разрыв страницы**. Также можно настроить автоматическую разбивку через параметры абзаца, включив запрет разрыва или разрыв перед абзацем. Это делается в настройках абзаца через контекстное меню или вкладку **Главное**.

### Разрывы страниц

Разрыв страницы вставляется через вкладку **Вставка → Разрыв страницы**. Это позволяет начать новый раздел или главу с новой страницы. Разрыв можно удалить, поставив курсор перед ним и нажав **Delete** или **Backspace**.

### Нумерация страниц

Нумерация страниц включается через вкладку **Вставка → Номер страницы**. Можно выбрать расположение номера: сверху или снизу, слева, справа или по центру. Для разных разделов можно задать свою нумерацию через настройки раздела. Если титульный лист не должен нумероваться, для первого раздела отключается нумерация.

## Практическая 8

### Колончатые тексты

Колончатый текст создаётся через вкладку **Разметка → Колонки**. Можно выбрать количество колонок, ширину и расстояние между ними. Также можно настроить разделительную линию между колонками. Колонки удобно использовать для газетного оформления или списков.

### Внесение исправлений в текст

Исправления можно вносить через вкладку **Рецензирование**. Там можно включить режим записи исправлений, и все изменения будут отображаться как правки. Также можно добавлять примечания через вкладку **Вставка → Примечание**. Примечания отображаются на полях и помогают комментировать текст без его изменения.

### Создание составных документов

Составной документ создаётся путём вставки одного документа в другой через вкладку **Вставка → Текст из файла**. Также можно использовать главный документ, в который включаются поддокументы. Это удобно для больших работ, состоящих из нескольких частей.

### Слияние документов

Слияние документов выполняется через вкладку **Вставка → Текст из файла**. Можно выбрать несколько файлов и вставить их в текущий документ. Также можно использовать мастер слияния для создания писем или документов по шаблону с подстановкой данных.

### Колонтитулы

Колонтитулы создаются через вкладку **Вставка → Верхний колонтитул** или **Нижний колонтитул**. В колонтитул можно вставить номер страницы, название документа, дату и другую информацию. Для разных разделов можно задавать разные колонтитулы через настройки раздела.

### Размещение колонтитулов

Колонтитулы размещаются сверху или снизу страницы. Их можно выравнивать по левому краю, правому краю или по центру. Также можно настроить разные колонтитулы для чётных и нечётных страниц через параметры страницы.

### Создание сносок и примечаний

Сноска создаётся через вкладку **Вставка → Сноска**. Сноска может быть внизу страницы или в конце документа. Примечание создаётся через вкладку **Вставка → Примечание** и отображается на полях. Сноски удобны для пояснений, а примечания — для комментариев.

### Создание оглавления

Оглавление создаётся через вкладку **Вставка → Оглавление и указатели**. Перед созданием оглавления нужно применить стили заголовков к разделам документа. Оглавление можно обновлять через контекстное меню по нажатию ПКМ. Также можно настроить уровень заголовков, которые попадут в оглавление.
