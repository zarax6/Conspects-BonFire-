
## Практическая работа №9. Работа с рисунками и научными формулами

### Вставка рисунков
Рисунок вставляется через **Вставка → Изображение**. В открывшемся диалоге выбирается файл на диске. После вставки рисунок по умолчанию привязывается к абзацу, в котором стоял курсор. Для точного позиционирования удобнее использовать привязку **«Как символ»**: правый клик по рисунку → **Привязка → Как символ**. В этом случае рисунок ведёт себя как обычный символ текста и перемещается вместе с абзацем при редактировании .

### Составление блок-схемы
Блок-схема собирается из фигур панели **Рисование** (включается через **Вид → Панели инструментов → Рисование**). Нужные блоки (прямоугольники, ромбы, стрелки) добавляются на страницу, соединяются линиями. Для удобства несколько фигур можно выделить (Shift+клик) и сгруппировать: правый клик → **Группировать**. После группировки блок-схема перемещается как единый объект.

### Переупорядочивание слоёв рисунка и вращение фигур
Порядок наложения объектов меняется через правый клик по рисунку → **Упорядочить**. Доступны варианты: **На передний план**, **На задний план**, **Вперёд** и **Назад** (перемещение на один уровень). Если объект перекрыт другим, его можно выбрать, нажимая **Tab** до тех пор, пока нужный объект не будет выделен . Вращение выполняется через правый клик → **Поворот** или перетаскиванием углового маркера в режиме поворота.

### Создание рисунка-подложки для текста
Чтобы рисунок оказался позади текста, используется обтекание **«На заднем плане»**. Правый клик по рисунку → **Обтекание → На заднем плане**. В отличие от варианта «Сквозное», при котором рисунок находится поверх текста, «На заднем плане» размещает изображение за текстом, и текст остаётся читаемым без изменения прозрачности рисунка .

### Управление обтеканием рисунка текстом
Основные режимы обтекания выбираются через правый клик по рисунку → **Обтекание**:
- **Нет обтекания** — текст располагается только над и под рисунком.
- **Обтекание по контуру** — текст огибает рисунок со всех сторон.
- **Сквозное** — рисунок накладывается на текст (требует настройки прозрачности).
- **На заднем плане** — рисунок за текстом.
- **Оптимальное** — текст заполняет пространство вокруг рисунка, но не подходит ближе 2 см к краю .
Точная настройка отступов между рисунком и текстом выполняется в диалоге **Формат → Изображение → Обтекание**, раздел «Отступы».

### Работа с научными формулами
Формула вставляется через **Вставка → Объект → Объект формулы**. Откроется редактор LibreOffice Math с полем ввода внизу. Формула записывается командами, например a sup 2 + b sup 2 = c sup 2 для получения \(a^2 + b^2 = c^2\). Элементы можно выбирать из панели символов, не запоминая команды вручную . После закрытия редактора формула остаётся в документе как OLE-объект; двойной клик по ней открывает Math для редактирования.

## Глава 2. Табличный процессор (LibreOffice Calc)

### Создание книг, форматирование, специальные возможности
Новая книга создаётся через **Файл → Создать → Электронная таблица**. Форматирование ячеек выполняется через правый клик → **Формат ячеек**: вкладки «Числа», «Шрифт», «Выравнивание», «Обрамление», «Фон». Специальные возможности Calc включают:
- **Условное форматирование** (**Формат → Условное форматирование**) — автоматическое изменение оформления ячеек при выполнении заданного условия.
- **Проверка данных** (**Данные → Проверка достоверности**) — ограничение вводимых значений (например, только числа из заданного диапазона).
- **Автофильтр** (**Данные → Автофильтр**) — быстрая фильтрация строк по значениям в столбцах.

### Формулы VBA (макросы)
В LibreOffice Calc макросы записываются на языке **LibreOffice Basic**, который является диалектом BASIC, а не VBA. VBA-код из Microsoft Excel может быть частично совместим, но не гарантированно.

Для записи макроса нужно сначала включить запись: **Сервис → Параметры → LibreOffice → Дополнительно → Разрешить запись макросов** (опция может быть недоступна в некоторых сборках). Затем: **Сервис → Макросы → Записать макрос**. Выполняются нужные действия в таблице, после чего запись останавливается. Calc сохраняет макрос в библиотеку **Standard** текущего документа или в «Мои макросы» .

Для написания макроса вручную: **Сервис → Макросы → Управление макросами → Basic**. В открывшемся IDE создаётся модуль и вводится код, например простая функция:
```basic
Function VOL(a, b, c)
    VOL = a * b * c
End Function
```
После сохранения функция становится доступна в ячейках как `=VOL(A1;B1;C1)` .
