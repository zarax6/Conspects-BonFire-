## Практическая 9

### Работа с рисунками в документе

Рисунки в документ вставляются через вкладку **Вставка** — кнопка **Изображение**. Можно вставить картинку из файла на компьютере или из галереи. После вставки рисунок можно перемещать, изменять его размер и настраивать положение на странице.

### Вставка рисунков

Вставить рисунок можно через вкладку **Вставка → Изображение**. Также можно просто перетащить файл картинки мышью прямо в документ. После вставки рисунок выделяется, и появляются маркеры для изменения размера и поворота.

### Составление блок-схемы

Блок-схема составляется с помощью панели **Рисование**, которая открывается через вкладку **Вид → Панель рисования**. Там есть готовые фигуры: прямоугольники, овалы, стрелки, ромбы и линии. Из этих фигур собирается блок-схема, а стрелками показываются связи между блоками.

### Переупорядочивание слоев рисунка и вращение фигур

Порядок слоёв меняется через контекстное меню по нажатию ПКМ на фигуре — там есть пункты **На передний план** и **На задний план**. Вращение фигур выполняется через маркеры поворота или через контекстное меню → **Положение и размер**. Там же можно задать точный угол поворота.

### Создание рисунка-подложки для текста

Рисунок-подложка создаётся через настройки обтекания. Нужно вставить рисунок, нажать на него ПКМ, выбрать **Обтекание → За текстом**. Тогда рисунок окажется позади текста и будет служить фоном. Также можно настроить прозрачность рисунка, чтобы текст был лучше виден.

### Управление обтеканием рисунка текстом

Обтекание настраивается через контекстное меню по нажатию ПКМ на рисунке → **Обтекание**. Можно выбрать варианты: **Обтекание по контуру**, **Обтекание рамкой**, **Перед текстом**, **За текстом**. Также можно задать отступы текста от рисунка и привязать рисунок к абзацу или странице.

### Работа с научными формулами

Формулы вставляются через вкладку **Вставка → Объект → Формула**. Открывается редактор формул, где можно писать математические выражения. Также можно вставлять готовые символы и шаблоны через панель редактора формул. Формула вставляется в текст как объект и её можно редактировать двойным щелчком.

## Глава 2. Табличный процессор (LibreOffice Calc)

### Табличный процессор

LibreOffice Calc — это табличный процессор с открытым исходным кодом. Он позволяет создавать таблицы, выполнять расчёты, строить диаграммы и работать с формулами. Как и Writer, Calc не имеет телеметрии и потребляет меньше ресурсов, чем продукты Microsoft.

### Создание книг

Новая книга создаётся через вкладку **Файл → Создать → Электронную таблицу**. Книга состоит из листов, между которыми можно переключаться внизу окна. Листы можно добавлять, удалять и переименовывать через контекстное меню по нажатию ПКМ на ярлыке листа.

### Форматирование

Форматирование ячеек выполняется через вкладку **Главное** или через контекстное меню → **Формат ячеек**. Можно изменить шрифт, размер, цвет текста и фона, выравнивание, а также формат чисел (денежный, процентный, дата и другие). Также можно объединять ячейки и настраивать границы.

### Специальные возможности

Специальные возможности настраиваются во вкладке **Сервис → Параметры**. Там можно включить автозаполнение, проверить орфографию, настроить фильтры и сортировку. Также можно использовать условное форматирование через вкладку **Главное → Условное форматирование**, чтобы ячейки меняли цвет в зависимости от значений.

### Формулы VB (макросы)

Макросы в Calc создаются через вкладку **Сервис → Макросы → Редактировать макросы**. Открывается редактор Basic, где можно писать код на языке LibreOffice Basic (похож на VB). Макросы позволяют автоматизировать работу с таблицами: заполнять ячейки, выполнять расчёты, строить отчёты. Запустить макрос можно через **Сервис → Макросы → Выполнить макрос**.
