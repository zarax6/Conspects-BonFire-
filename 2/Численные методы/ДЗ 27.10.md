## 1. Методы прямоугольников и трапеций
Для нахождения приближённого значения интеграла применяются методы прямоугольников и трапеций.

Рассмотрим вычисление интеграла от 0 до 2 для функции f(x) = x² + 1.

Точное значение интеграла определяется следующим образом: [x³/3 + x] от 0 до 2 = 8/3 + 2 = 14/3 ≈ 4.667.

Сначала рассчитывается шаг разбиения и определяются узлы: h = (2 − 0) / 2 = 1; x₀ = 0, x₁ = 1, x₂ = 2.

Вычислим значения функции в найденных узлах: f(0) = 1, f(1) = 2, f(2) = 5.

При использовании метода левых прямоугольников получаем: 1 · (1 + 2) = 3.

Для правых прямоугольников результат будет следующим: 1 · (2 + 5) = 7.

Метод средних прямоугольников даёт значение: 1 · (f(0.5) + f(1.5)) = 1.25 + 3.25 = 4.5.

При применении метода трапеций вычисление выполняется по формуле: (1 / 2) · (1 + 2 · 2 + 5) = 5.
## 2. Метод Симпсона
Метод Симпсона используется для приближённого вычисления определённых интегралов с помощью параболической интерполяции.

Рассмотрим интеграл от 1 до 3 функции f(x) = 1 / x.

Его точное значение находится следующим образом: [ln(x)] от 1 до 3 = ln(3) ≈ 1.0986.

Определяем шаг и узлы разбиения: h = (3 − 1) / 2 = 1; x₀ = 1, x₁ = 2, x₂ = 3.

Значения функции в узлах равны: f(1) = 1, f(2) = 0.5, f(3) = 1/3 ≈ 0.3333.

Подставляя полученные значения в формулу Симпсона, получаем: (1 / 3) · (1 + 4 · 0.5 + 1/3) = 10/9 ≈ 1.1111.

## 3. Метод Гаусса
Метод Гаусса применяется для вычисления интегралов с использованием специальных узлов и весовых коэффициентов.

Вычислим интеграл от 0 до 1 функции f(x) = x³ + x.

Точное значение определяется через первообразную: [x⁴/4 + x²/2] от 0 до 1 = 0.25 + 0.5 = 0.75.

Для перехода к стандартному промежутку [-1, 1] выполняется замена переменной: x = (t + 1) / 2, dx = (1 / 2) dt.

Определяются узлы и соответствующие им веса: t₁,₂ = ±1 / √3 ≈ ±0.57735, веса A₁ = 1, A₂ = 1.

Первый узел вычисляется следующим образом: x₁ = (-0.57735 + 1) / 2 ≈ 0.211325.

Значение функции в первом узле: f(x₁) = 0.211325³ + 0.211325 ≈ 0.22076.

Второй узел определяется по формуле: x₂ = (0.57735 + 1) / 2 ≈ 0.788675.

Значение функции во втором узле: f(x₂) = 0.788675³ + 0.788675 ≈ 1.27922.

Используя формулу Гаусса, получаем приближённое значение интеграла: (1 / 2) · (1 · 0.22076 + 1 · 1.27922) = 1.49998 / 2 ≈ 0.75.
