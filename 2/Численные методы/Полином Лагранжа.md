Интерполяция используется для вычисления промежуточных значений функции по известным дискретным точкам, называемым узлами интерполяции. Если узлы попарно различны, то можно построить интерполяционный полином, который совпадает с функцией в заданных точках. Для нахождения его коэффициентов применяется определитель Вандермонда.

Полином степени не выше n имеет общий вид: P_n(x) = a_0 + a_1·x + ... + a_n·x^n.

Интерполяционный полином Лагранжа формируется как сумма произведений значений функции на базисные полиномы: L_n(x) = Σ(i=0 до n) y_i·l_i(x) = Σ(i=0 до n) y_i·(Π(j=0 до n, j≠i) (x − x_j)/(x_i − x_j)).

Базисные полиномы обладают свойством принимать значение 1 в собственном узле и 0 во всех остальных узлах: l_i(x_i) = 1, l_i(x_j) = 0 при i ≠ j.

Рассмотрим пример, в котором заданы узлы x = 1, 2, 3 и значения функции y = 5, 8, 13. Базисные полиномы для этих точек имеют следующий вид:
l_0(x) = ((x − 2)·(x − 3))/2
l_1(x) = −(x − 1)·(x − 3)
l_2(x) = ((x − 1)·(x − 2))/2

Общий полином Лагранжа получается сложением базисных полиномов с соответствующими коэффициентами: L_2(x) = 5·l_0(x) + 8·l_1(x) + 13·l_2(x).

Подставляя нужное значение аргумента, можно вычислить приближённое значение функции. Например, при x = 1.5 получается L_2(1.5) = 6.25.

Погрешность интерполяции определяется разностью между исходной функцией и интерполяционным полиномом. Остаточный член записывается следующим образом: f(x) − L_n(x) = (f^(n+1)(ξ)/(n+1)!)·Π(i=0 до n)(x − x_i).

Модуль погрешности ограничивается сверху через максимальное значение производной порядка n+1 и произведение отклонений от узлов: |f(x) − L_n(x)| ≤ (max|f^(n+1)(x)|/(n+1)!)·Π(i=0 до n)|x − x_i|.
