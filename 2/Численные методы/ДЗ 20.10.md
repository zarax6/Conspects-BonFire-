# Численное интегрирование

**Исходные параметры:**
Интервал интегрирования: [0, 2].
Число частей разбиения: n = 2.
Величина шага: h = (b − a) / n = (2 − 0) / 2 = 1.
Точки разбиения: x₀ = 0, x₁ = 1, x₂ = 2.
## 1. Вычисление интеграла от x³

Точное значение интеграла: ∫₀² x³ dx = [x⁴ / 4]₀² = 16 / 4 − 0 = 4.
**Метод прямоугольников (средних):**
I = h · (f((x₀ + x₁)/2) + f((x₁ + x₂)/2)) = 1 · (0.5³ + 1.5³) = 0.125 + 3.375 = 3.5.
**Метод трапеций:**
Iₜ = h · ((f(x₀) + f(x₂)) / 2 + f(x₁)) = 1 · ((0³ + 2³) / 2 + 1³) = 4 + 1 = 5.
**Метод парабол (Симпсона):**
Iₛ = (h / 3) · (f(x₀) + 4·f(x₁) + f(x₂)) = (1 / 3) · (0³ + 4·1³ + 2³) = 12 / 3 = 4.
## 2. Вычисление интеграла от x³ + 1

Точное значение: ∫₀² (x³ + 1) dx = [x⁴ / 4 + x]₀² = (4 + 2) − 0 = 6.
**Метод прямоугольников (средних):**
I = h · (f((x₀ + x₁)/2) + f((x₁ + x₂)/2)) = 1 · ((0.5³ + 1) + (1.5³ + 1)) = 1.125 + 4.375 = 5.5.
**Метод трапеций:**
Iₜ = h · ((f(x₀) + f(x₂)) / 2 + f(x₁)) = 1 · (((0³ + 1) + (2³ + 1)) / 2 + (1³ + 1)) = (1 + 9) / 2 + 2 = 7.
**Метод парабол (Симпсона):**
Iₛ = (h / 3) · (f(x₀) + 4·f(x₁) + f(x₂)) = (1 / 3) · ((0³ + 1) + 4·(1³ + 1) + (2³ + 1)) = (1 + 8 + 9) / 3 = 6.
## 3. Вычисление интеграла от √x

Точное значение: ∫₀² √x dx = [(2/3)·x^(3/2)]₀² = (4√2) / 3 ≈ 1.8856.
**Метод прямоугольников (средних):**
I = h · (f((x₀ + x₁)/2) + f((x₁ + x₂)/2)) = 1 · (√0.5 + √1.5) ≈ 0.7071 + 1.2247 = 1.9318.
**Метод трапеций:**
Iₜ = h · ((f(x₀) + f(x₂)) / 2 + f(x₁)) = 1 · ((√0 + √2) / 2 + √1) ≈ 1.4142 / 2 + 1 = 1.7071.
**Метод парабол (Симпсона):**
Iₛ = (h / 3) · (f(x₀) + 4·f(x₁) + f(x₂)) = (1 / 3) · (√0 + 4·√1 + √2) ≈ (0 + 4 + 1.4142) / 3 ≈ 1.8047.
## 4. Сравнение полученных результатов

|Интеграл|Точное значение|Прямоугольники|Трапеции|Симпсона|
|---|---|---|---|---|
|∫₀² x³ dx|4|3.5|5|4|
|∫₀² (x³ + 1) dx|6|5.5|7|6|
|∫₀² √x dx|1.8856|1.9318|1.7071|1.8047|

## Вывод

В результате сравнения численных методов интегрирования можно сделать вывод, что для функций, содержащих кубическую степень, например x³, наиболее подходящим является метод Симпсона, поскольку он позволяет получить результат, совпадающий с точным значением интеграла.

Для функции √x более подходящим оказался метод прямоугольников, так как его результат ближе к точному значению интеграла, чем результаты остальных рассмотренных методов.
