## Обыкновенные дифференциальные уравнения

Обыкновенное дифференциальное уравнение (ОДУ) — это уравнение, которое содержит независимую переменную x, неизвестную функцию y(x) и её производные различных порядков. Порядок дифференциального уравнения определяется самой высокой производной, входящей в его состав. По характеру зависимости функции и её производных уравнения подразделяются на линейные, в которых все неизвестные величины входят в первой степени, и нелинейные.

Линейное однородное дифференциальное уравнение первого порядка записывается следующим образом: y' + p(x)y = 0. Для его решения применяется метод разделения переменных. Задача Коши заключается в нахождении решения уравнения y' = f(x, y), которое удовлетворяет заданному начальному условию y(x₀) = y₀. Геометрически это означает, что из множества возможных решений выбирается одна интегральная кривая, проходящая через определённую точку.

Для численного решения ОДУ рассматриваемый промежуток разбивается на отдельные шаги с величиной h. При этом формируется последовательность точек сетки, определяемая выражением xᵢ₊₁ = xᵢ + h.

Простейшим способом численного решения является метод Эйлера. Он основан на использовании касательной в начальной точке каждого шага для вычисления следующего значения функции. Формула метода имеет вид: yᵢ₊₁ = yᵢ + h · f(xᵢ, yᵢ). Данный метод отличается простотой реализации, однако его точность невысока. Погрешность на одном шаге имеет порядок O(h²), а общая погрешность составляет O(h).

Уточнённый, или модифицированный, метод Эйлера позволяет повысить точность вычислений благодаря использованию схемы «предиктор — корректор». На первом этапе определяется предварительное значение функции, называемое предиктором: ŷᵢ₊₁ = yᵢ + h · f(xᵢ, yᵢ). Затем выполняется коррекция результата с помощью среднего значения производных в начале и конце шага: yᵢ₊₁ = yᵢ + (h / 2) · (f(xᵢ, yᵢ) + f(xᵢ₊₁, ŷᵢ₊₁)). Использование данного подхода обеспечивает второй порядок точности, а глобальная погрешность имеет порядок O(h²).

Классический метод Рунге — Кутты четвёртого порядка позволяет получить более точное решение дифференциального уравнения без вычисления производных высоких порядков. Для этого на каждом шаге вычисляются четыре вспомогательных коэффициента:

k₁ = f(xᵢ, yᵢ);
k₂ = f(xᵢ + h/2, yᵢ + (h/2)·k₁);
k₃ = f(xᵢ + h/2, yᵢ + (h/2)·k₂);
k₄ = f(xᵢ + h, yᵢ + h·k₃).

После нахождения всех коэффициентов вычисляется значение функции на следующем шаге по формуле: yᵢ₊₁ = yᵢ + (h/6)·(k₁ + 2k₂ + 2k₃ + k₄).

Данный метод обеспечивает высокую точность численного решения, а его глобальная погрешность имеет порядок O(h⁴).
