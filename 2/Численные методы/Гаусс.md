
### Входные данные:

- A — квадратная матрица коэффициентов размером 3×3;
- b — столбец свободных членов;
- eps — допустимая погрешность (eps > 0).
### Выходные данные:

- x — найденный вектор неизвестных;
- r — вектор невязок;
- max_r — наибольшее значение невязки.
### Порядок выполнения алгоритма:

1. Построить расширенную матрицу, объединив матрицу коэффициентов с вектором свободных членов: M = [A | b].
    
2. Выполнить прямой этап метода Гаусса:
    
    1.  Перебрать k от 0 до 1.
    2.  Для каждой строки i, расположенной ниже ведущей строки, определить коэффициент преобразования: m = M[i][k] / M[k][k].
    3. Последовательно изменить элементы строки по формуле: M[i][j] = M[i][j] − m * M[k][j], где j изменяется от k до 3.
    4. После завершения преобразований получить треугольную матрицу.
3. Выполнить обратный этап:
    1. Начать с последней строки и двигаться к первой, перебирая i от 2 до 0 с шагом −1.
    2.  Для каждой строки обнулить промежуточную сумму: S = 0.
    3. Вычислить сумму произведений коэффициентов на уже найденные неизвестные: S = S + M[i][j] * x[j], где j изменяется от i+1 до 2.ё
    4.  Найти очередное неизвестное: x[i] = (M[i][3] − S) / M[i][i].
4. Рассчитать невязки:
    1.  Для каждой строки исходной матрицы выполнить вычисления при i от 0 до 2.
    2. Задать начальное значение суммы: S = 0. 
    3. Вычислить сумму произведений коэффициентов на найденные решения: S = S + A[i][j] * x[j], где j изменяется от 0 до 2.
    4.  Определить невязку: r[i] = b[i] − S.
5. Определить максимальную невязку: max_r = max(|r[i]|).
6. Проверить полученную точность:
    1. Если max_r < eps, вывести сообщение «Точность достигнута».
    2.  Если max_r ≥ eps, вывести сообщение «Точность не достигнута».
7. Отобразить найденный вектор решений x, вектор невязок r и максимальную невязку max_r.
8. Завершить работу алгоритма.

``` Python
A = [
    [1.0, 1.0, 1.0],
    [1.2, 3.0, 1.0],
    [1.0, -1.0, -1.0]
]

b = [4.0, 9.0, -2.0]
eps = 0.001

n = len(b)

M = [A[i][:] + [b[i]] for i in range(n)]

print("Начальная расширенная матрица M:")
for row in M:
    print(row)
print()

for k in range(n - 1):
    for i in range(k + 1, n):
        coef = M[i][k] / M[k][k]

        for j in range(k, n + 1):
            M[i][j] = M[i][j] - coef * M[k][j]

print("Матрица после прямого этапа:")
for row in M:
    print(row)
print()

x = [0.0] * n

for i in range(n - 1, -1, -1):
    summ = 0.0

    for j in range(i + 1, n):
        summ = summ + M[i][j] * x[j]

    x[i] = (M[i][n] - summ) / M[i][i]

print("Полученный вектор x:")
print(x)
print()

r = [0.0] * n

for i in range(n):
    summ = 0.0

    for j in range(n):
        summ = summ + A[i][j] * x[j]

    r[i] = b[i] - summ

max_r = max(abs(value) for value in r)

if max_r < eps:
    print("Точность достигнута")
else:
    print("Точность не достигнута")

print("Вектор невязок r:", r)
print("Наибольшая невязка max_r:", max_r)
```
