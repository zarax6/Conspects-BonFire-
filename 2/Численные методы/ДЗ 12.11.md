## 1. Алгоритм метода Рунге — Кутты

Дано дифференциальное уравнение: dv/dt = (u/m)  (dm/dt) - g.

Начальные условия и параметры:

- v(0) = 0 — начальная скорость.
- m(0) = m0 = 1000 кг — начальная масса.
- u = 2000 м/с — скорость истечения газов.
- dm/dt = -10 кг/с — скорость изменения массы.
- g = 9.8 м/с² — ускорение свободного падения.
- t = 50 с — время расчёта.
- h = 1 с — шаг интегрирования.

Масса ракеты изменяется по формуле: m(t) = 1000 - 10t.

Для применения метода Рунге — Кутты обозначим правую часть уравнения:

f(t, v) = -20000 / (1000 - 10t) - 9.8.

Формулы метода Рунге — Кутты 4-го порядка:

- k1 = f(t, v)
- k2 = f(t + h/2, v + hk1/2)
- k3 = f(t + h/2, v + hk2/2)
- k4 = f(t + h, v + hk3)
- v_new = v + (h/6)(k1 + 2k2 + 2k3 + k4)

Алгоритм выполнения:

1. Задать начальные значения и константы.
2. Установить начальную скорость v = 0.
3. Рассчитать массу ракеты для текущего времени.
4. Вычислить коэффициенты k1, k2, k3, k4.
5. Рассчитать новую скорость по формуле Рунге — Кутты.
6. Увеличить время на шаг h.
7. Повторять вычисления до достижения 50 секунд.
8. Вывести конечную скорость ракеты.
## 2. Реализация программы на Python
``` Python
u = 2000
m0 = 1000
dm = -10
g = 9.8

t = 0
v = 0
h = 1

def f(t):
    m = m0 + dm * t
    return (u / m) * dm - g

while t < 50:
    k1 = f(t)
    k2 = f(t + h / 2)
    k3 = f(t + h / 2)
    k4 = f(t + h)

    v = v + (h / 6) * (k1 + 2*k2 + 2*k3 + k4)

    t += h

print("Метод Рунге-Кутты 4-го порядка")
print("Время:", t, "с")
print("Скорость ракеты:", round(v, 6), "м/с")

```
