CREATE TABLE - Название сущности (внутри перечисляем атрибуты их свойства)
Начинать нужно с родительских таблиц, у которых нет родительского ключа не зависимо от других.
Нельзя повторно создать сущность если она уже есть, е надо удалить. 

IDENTITY - Автоматическое увеличение элемента, 1 цифра в скобках - начинается с этого элемента а 2 цифра - шаг

DROP TABLE - Удаление таблицы, все данные, триггеры, ограничения с ней. Удалять таблицы нужно в обратном порядке, не то родительских а от дочерних.
Нельзя удалить то чего нету.
