Команда для создания атрибутов:
ALTER TABLE Название_Сущности
ADD Название_атрибута

Пример: Добавим в сющность блюдо атрибут "Вес порции (г)"
ALTER TABLE Блюдо
ADD Вес_порции INT NULL;

SELECT * FROM  блюдо

Пример 2: Добавим в Ингредиент атрибут "Калорийность" с ограничением CHECK:
ALTER TABLE Ингредиент
ADD Калорийность SMALLINT NULL CHECK (Калорийность > 0);

SELECT * FROM  Ингредиент

При изменении удалении атрибутов не должно быть противоречия с ограничениями

Если есть противоречия, удалить ограничения после этого можно изменять и удалять атрибут

При необходимости, после изменения или удаления снова добавить ограничения

Удаление атрибута:
ALTER TABLE Блюдо
DROP COLUMN Вес_порции;
