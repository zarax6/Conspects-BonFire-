
Операторы запроса на ввод сущности:
- FROM - в нем указываются какую сущность выводим (он обязателен)
- SELECT - Выводит атрибуты и сущности (SELECT * - Выводит все атрибуты)
- INSERT INTO - Команда для заполнения сущности данными
- DEFAULT - Выводит значение по умолчанию
- WHERE - фильтрует строки по условию
